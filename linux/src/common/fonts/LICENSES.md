# Fonts in SilverOS

All fonts are under the SIL Open Font License 1.1 (https://openfontlicense.org), which permits
use, modification and redistribution (including embedding in software) as long as modified
fonts do not use the original name. The `.sdf` files here are baked glyph-distance atlases
made by `src/art/mkfont.py`.

| File          | Source font                          | Notes |
|---------------|--------------------------------------|-------|
| `scrawl.sdf`  | Bowlby One (Vernon Adams / Google Fonts) | Modified derivative, renamed **Silver Scrawl** (the original reserves the names "Bowlby" and "Bowlby One"): fattened, roughened outlines, dry-brush bites, splatter, per-letter tilt and size. |
| `caption.sdf` | Michroma (Vernon Adams / Google Fonts)   | Unmodified glyph shapes. |
| `text.sdf`    | Inter Medium (The Inter Project Authors) | Unmodified glyph shapes. |
